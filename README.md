# Keerthana Rao Lopelly - Personal Portfolio

Full Stack Development Assignment-1.

A responsive personal portfolio website for a Computer Science Engineering student, built with HTML, CSS and JavaScript.

## Live Website

https://lopellykeerthana.github.io/keerthana-portfolio/

## Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome icons (CDN)

## Features

- Responsive navigation bar with mobile menu
- Smooth scrolling and active link highlighting
- Home/Profile section
- About Me
- Education
- Skills
- Experience
- Projects
- Contact form
- Client-side form validation
- Dynamic current year in the footer
- Responsive layout for desktop, tablet and mobile
- GitHub and email links

## Note About the Contact Form

The contact form only validates the fields in the browser and shows a message. It does not send emails, because this is a front-end-only project with no backend or form service connected.

## Project Structure

- index.html - page structure and content
- style.css - styling and responsive layout
- script.js - mobile menu, active link highlighting, form validation
- README.md - project description

## How to Run

Open index.html in a web browser.

For development, you can also use the VS Code Live Server extension.
